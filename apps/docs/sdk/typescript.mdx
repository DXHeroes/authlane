---
title: 'TypeScript SDK'
description: 'Server-side client for the Authlane control plane'
---

```bash
pnpm add @authlane/sdk
```

```typescript
import { Authlane } from '@authlane/sdk';

const authlane = new Authlane({
  apiKey: process.env.AUTHLANE_API_KEY!,
  baseUrl: 'https://authlane.example.com',
});
```

All methods return `{ data, error }` and do not throw for API responses. Constructor configuration errors still throw. The client sends `Authorization: Bearer ak_...` and is server-only.

## Capabilities

```typescript
await authlane.capabilities.get({
  externalUserId: 'user_123',
  format: 'mcp', // or openai
});
```

Use this hot-read endpoint when building an agent request. It returns connection status and definitions in one snapshot with a stable version hash.

## Connections

```typescript
await authlane.connections.list({ externalUserId: 'user_123' });

await authlane.credentialLeases.create({
  externalUserId: 'user_123',
  serviceId: 'github',
});
```

Credential leases require `credentials:issue`, are audited, return `Cache-Control: no-store, private`, and never include OAuth refresh or ID tokens. Issue them only on a trusted server and do not persist them.

## Connect sessions

```typescript
await authlane.connectSessions.create({
  externalUserId: 'user_123',
  allowedServices: ['github'],
  allowedOrigin: 'https://app.example.com',
  expiresInSeconds: 600,
});
```

Return only the resulting `url` to the browser.

## Services and tools

```typescript
await authlane.services.list();
await authlane.tools.list({ externalUserId: 'user_123', format: 'openai' });
```

Authlane returns definitions only. Execute provider tools with the matching `@authlane/integration-*` package in your own runtime.
