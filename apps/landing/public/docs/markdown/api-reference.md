# API reference

Inspect the complete read-only Authlane OpenAPI control-plane contract.

The rendered reference is generated from Authlane's canonical OpenAPI 3.1 specification. It is a
read-only contract browser: provider execution remains in your SaaS runtime.

## Operations

Review every control-plane operation, required authentication scheme, scope, response status, and
available request or response example on the [full API reference](/docs/api-reference).

## Webhooks

Inspect the signed lifecycle webhook contract and example payloads, then implement verification
with the [webhook guide](/docs/guides/webhooks).

Browse the complete request, response, error, connection, service, tool, and webhook schemas. Use
