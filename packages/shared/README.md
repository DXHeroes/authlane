# @authlane/shared

Shared public types, API scopes, service identifiers, errors, and utilities used by the Authlane
TypeScript SDK and direct-execution integration packages.

```bash
pnpm add @authlane/shared
```

Most applications should install `@authlane/sdk` instead. This package is intended for framework
adapters and custom integrations that need Authlane's stable shared contracts.
