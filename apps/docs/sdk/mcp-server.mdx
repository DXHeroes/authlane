## Overview

Authlane provides an MCP (Model Context Protocol) server that exposes all connected integrations as tools for AI agents.

## Installation

```bash
npm install @authlane/mcp-server
```

## Claude Desktop Integration

### 1. Install MCP Server

```bash
npm install -g @authlane/mcp-server
```

### 2. Configure Claude Desktop

Add to `~/Library/Application Support/Claude/claude_desktop_config.json`:

```json
{
  "mcpServers": {
    "authlane": {
      "command": "authlane-mcp-server",
      "env": {
        "AUTHLANE_API_KEY": "sk_live_...",
        "AUTHLANE_USER_ID": "your_user_id"
      }
    }
  }
}
```

### 3. Restart Claude Desktop

Claude will now have access to all your connected integrations as tools.

## Usage in Claude

Once configured, you can use integrations directly:

```
You: Create a GitHub issue titled "Bug in login" in authlane/authlane repo

Claude: I'll create that issue for you.
[Uses github_create_issue tool]
Done! Issue #123 created: https://github.com/authlane/authlane/issues/123

You: Send a Slack message to #engineering channel

Claude: What message would you like to send?

You: "Deployed v1.2.0 to production"

Claude: [Uses slack_send_message tool]
Message sent to #engineering!
```

## LangChain Integration

Use Authlane tools in LangChain:

```typescript
import { AutolaneToolkit } from '@authlane/mcp-server/langchain';
import { ChatOpenAI } from '@langchain/openai';
import { AgentExecutor, createOpenAIFunctionsAgent } from 'langchain/agents';

const toolkit = new AutolaneToolkit({
  apiKey: process.env.AUTHLANE_API_KEY!,
  userId: 'user_123',
});

const tools = await toolkit.getTools();

const agent = await createOpenAIFunctionsAgent({
  llm: new ChatOpenAI({ temperature: 0 }),
  tools,
  prompt: /* ... */,
});

const executor = new AgentExecutor({
  agent,
  tools,
});

const result = await executor.invoke({
  input: 'Create a GitHub issue for the bug we discussed',
});
```

## Available Tools

The MCP server exposes all tools from connected integrations:

### GitHub
- `github_create_issue`
- `github_list_issues`
- `github_create_pr`
- `github_search_code`

### Slack
- `slack_send_message`
- `slack_list_channels`
- `slack_create_channel`

### Linear
- `linear_create_issue`
- `linear_list_issues`
- `linear_update_issue`

And many more across 15+ integrations.

## Custom MCP Server

Run MCP server programmatically:

```typescript
import { createMCPServer } from '@authlane/mcp-server';

const server = createMCPServer({
  apiKey: process.env.AUTHLANE_API_KEY!,
  userId: 'user_123',
  port: 3001,
});

server.start();
console.log('MCP server running on http://localhost:3001');
```
