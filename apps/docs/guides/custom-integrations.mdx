## Overview

Authlane supports adding custom integrations beyond the built-in 15 services. This guide shows you how to create a new integration from scratch.

## Integration Structure

Each integration consists of:

```
/integrations/{service-id}/
├─ config.yaml          # OAuth & service configuration
├─ tools.ts             # Tool definitions (MCP/OpenAI format)
├─ README.md            # Setup guide
└─ logo.svg             # Service logo (optional)
```

## Step-by-Step Guide

Let's create a **Trello** integration as an example.

### Step 1: Create Integration Directory

```bash
mkdir -p integrations/trello
cd integrations/trello
```

### Step 2: Create config.yaml

```yaml
# integrations/trello/config.yaml
id: trello
name: Trello
description: Project management and collaboration tool
category: productivity
logo: ./logo.svg

oauth:
  type: oauth2
  authorizationUrl: https://trello.com/1/authorize
  tokenUrl: https://trello.com/1/OAuthGetAccessToken
  scopes:
    - read
    - write
  pkce: false  # Trello doesn't support PKCE

  # OAuth 1.0a (Trello uses this)
  version: "1.0a"
  requestTokenUrl: https://trello.com/1/OAuthGetRequestToken

endpoints:
  base: https://api.trello.com/1

credentials:
  type: oauth1  # or oauth2, api_key
  fields:
    - oauth_token
    - oauth_token_secret
    - oauth_verifier

rateLimit:
  requests: 300
  window: 10  # seconds

metadata:
  docs: https://developer.atlassian.com/cloud/trello/rest/
  support: https://trello.com/support
```

<Note>
  Most modern services use OAuth 2.0. Trello uses OAuth 1.0a, which requires a different flow.
</Note>

### Step 3: Create Tools

Tools are exposed in two formats:

1. **MCP** (Model Context Protocol) - for Claude Desktop
2. **OpenAI** - for OpenAI function calling

```typescript
// integrations/trello/tools.ts
import type { Tool } from '@authlane/shared';

export const tools: Tool[] = [
  {
    name: 'trello_list_boards',
    description: 'List all boards accessible by the authenticated user',
    inputSchema: {
      type: 'object',
      properties: {
        filter: {
          type: 'string',
          enum: ['all', 'open', 'closed', 'starred'],
          description: 'Filter boards by status',
          default: 'open',
        },
      },
    },
    execute: async ({ credentials, parameters }) => {
      const response = await fetch(
        `https://api.trello.com/1/members/me/boards?filter=${parameters.filter}`,
        {
          headers: {
            Authorization: `OAuth oauth_consumer_key="${credentials.client_id}", oauth_token="${credentials.oauth_token}"`,
          },
        }
      );

      if (!response.ok) {
        throw new Error(`Trello API error: ${response.statusText}`);
      }

      return await response.json();
    },
  },

  {
    name: 'trello_create_card',
    description: 'Create a new card in a Trello list',
    inputSchema: {
      type: 'object',
      properties: {
        listId: {
          type: 'string',
          description: 'The ID of the list to create the card in',
        },
        name: {
          type: 'string',
          description: 'The name/title of the card',
        },
        desc: {
          type: 'string',
          description: 'The description of the card (optional)',
        },
        due: {
          type: 'string',
          description: 'Due date in ISO 8601 format (optional)',
        },
        labels: {
          type: 'array',
          items: { type: 'string' },
          description: 'Array of label IDs (optional)',
        },
      },
      required: ['listId', 'name'],
    },
    execute: async ({ credentials, parameters }) => {
      const response = await fetch('https://api.trello.com/1/cards', {
        method: 'POST',
        headers: {
          'Content-Type': 'application/json',
          Authorization: `OAuth oauth_consumer_key="${credentials.client_id}", oauth_token="${credentials.oauth_token}"`,
        },
        body: JSON.stringify({
          idList: parameters.listId,
          name: parameters.name,
          desc: parameters.desc,
          due: parameters.due,
          idLabels: parameters.labels,
        }),
      });

      if (!response.ok) {
        throw new Error(`Failed to create card: ${response.statusText}`);
      }

      return await response.json();
    },
  },

  {
    name: 'trello_get_card',
    description: 'Get details of a specific Trello card',
    inputSchema: {
      type: 'object',
      properties: {
        cardId: {
          type: 'string',
          description: 'The ID of the card to retrieve',
        },
      },
      required: ['cardId'],
    },
    execute: async ({ credentials, parameters }) => {
      const response = await fetch(
        `https://api.trello.com/1/cards/${parameters.cardId}`,
        {
          headers: {
            Authorization: `OAuth oauth_consumer_key="${credentials.client_id}", oauth_token="${credentials.oauth_token}"`,
          },
        }
      );

      if (!response.ok) {
        throw new Error(`Card not found: ${response.statusText}`);
      }

      return await response.json();
    },
  },
];
```

### Step 5: Create README

```markdown
# Trello Integration

Connect to Trello to manage boards, lists, and cards.

## Setup

### 1. Create Trello Power-Up

1. Go to [trello.com/power-ups/admin](https://trello.com/power-ups/admin)
2. Click **Create a Power-Up**
3. Fill in:
   - **Name**: Your App Name
   - **Redirect URL**: `https://api.authlane.com/api/v1/oauth/callback`

### 2. Get API Credentials

- Copy **API Key**
- Copy **API Secret**

### 3. Configure in Authlane

\`\`\`bash
curl -X POST https://api.authlane.com/api/v1/admin/services/trello/credentials \\
  -H "Authorization: Bearer YOUR_ADMIN_API_KEY" \\
  -H "Content-Type: application/json" \\
  -d '{
    "tenantId": "your-tenant-id",
    "clientId": "YOUR_TRELLO_API_KEY",
    "clientSecret": "YOUR_TRELLO_API_SECRET"
  }'
\`\`\`

## Available Tools

### trello_list_boards

List all boards accessible by the user.

**Parameters:**
- `filter` (optional): Filter by status (`open`, `closed`, `starred`)

### trello_create_card

Create a new card in a list.

**Parameters:**
- `listId` (required): Target list ID
- `name` (required): Card title
- `desc` (optional): Card description
- `due` (optional): Due date (ISO 8601)
- `labels` (optional): Array of label IDs

### trello_get_card

Get details of a specific card.

**Parameters:**
- `cardId` (required): Card ID to retrieve
```

### Step 6: Test Integration

Create a test script:

```bash
#!/bin/bash
# integrations/trello/test-oauth.sh

USER_ID="test_user"
SERVICE_ID="trello"
BASE_URL="http://localhost:3000"

echo "Step 1: Get authorization URL"
AUTH_RESPONSE=$(curl -s -X GET \
  "$BASE_URL/api/v1/oauth/authorize?user_id=$USER_ID&service_id=$SERVICE_ID" \
  -H "Authorization: Bearer $AUTHLANE_API_KEY")

AUTH_URL=$(echo $AUTH_RESPONSE | jq -r '.url')
STATE=$(echo $AUTH_RESPONSE | jq -r '.state')

echo "Visit this URL to authorize:"
echo $AUTH_URL
echo ""
echo "After authorization, paste the oauth_verifier here:"
read VERIFIER

echo "Step 2: Exchange verifier for token"
curl -X POST "$BASE_URL/api/v1/oauth/callback" \
  -H "Content-Type: application/json" \
  -d "{
    \"state\": \"$STATE\",
    \"oauth_verifier\": \"$VERIFIER\"
  }"

echo ""
echo "Step 3: Test connection"
curl -s -X GET \
  "$BASE_URL/api/v1/users/$USER_ID/connections/$SERVICE_ID/health" \
  -H "Authorization: Bearer $AUTHLANE_API_KEY" | jq
```

Run test:

```bash
chmod +x integrations/trello/test-oauth.sh
./integrations/trello/test-oauth.sh
```

## Advanced Features

### Custom Authentication

For non-OAuth services (e.g., API key auth):

```yaml
# config.yaml
oauth:
  type: api_key

credentials:
  type: api_key
  fields:
    - api_key
    - api_secret
```

```typescript
// tools.ts
execute: async ({ credentials, parameters }) => {
  const response = await fetch('https://api.service.com/endpoint', {
    headers: {
      'X-API-Key': credentials.api_key,
      'X-API-Secret': credentials.api_secret,
    },
  });
  return await response.json();
}
```

### Pagination

Handle paginated responses:

```typescript
{
  name: 'service_list_items',
  description: 'List items with pagination',
  inputSchema: {
    type: 'object',
    properties: {
      page: {
        type: 'number',
        description: 'Page number (starting from 1)',
        default: 1,
      },
      perPage: {
        type: 'number',
        description: 'Items per page',
        default: 50,
        maximum: 100,
      },
    },
  },
  execute: async ({ credentials, parameters }) => {
    const response = await fetch(
      `https://api.service.com/items?page=${parameters.page}&per_page=${parameters.perPage}`,
      {
        headers: {
          Authorization: `Bearer ${credentials.access_token}`,
        },
      }
    );

    const data = await response.json();
    const linkHeader = response.headers.get('Link');

    return {
      items: data,
      pagination: {
        page: parameters.page,
        perPage: parameters.perPage,
        hasNext: linkHeader?.includes('rel="next"'),
        total: parseInt(response.headers.get('X-Total-Count') || '0'),
      },
    };
  },
}
```

### Error Handling

Provide detailed error messages:

```typescript
execute: async ({ credentials, parameters }) => {
  try {
    const response = await fetch('https://api.service.com/endpoint', {
      headers: {
        Authorization: `Bearer ${credentials.access_token}`,
      },
    });

    if (!response.ok) {
      const error = await response.json();

      // Map API errors to user-friendly messages
      if (response.status === 401) {
        throw new Error('Authentication failed. Please reconnect your account.');
      } else if (response.status === 403) {
        throw new Error(`Permission denied: ${error.message}`);
      } else if (response.status === 429) {
        throw new Error('Rate limit exceeded. Please try again later.');
      } else {
        throw new Error(`API error: ${error.message || response.statusText}`);
      }
    }

    return await response.json();
  } catch (error) {
    if (error instanceof Error) {
      throw error;
    }
    throw new Error('Unknown error occurred');
  }
}
```

### Webhooks Support

For services that support webhooks:

```yaml
# config.yaml
webhooks:
  supported: true
  events:
    - card.created
    - card.updated
    - card.deleted
  verificationMethod: hmac_sha256
```

```typescript
// integrations/trello/webhooks.ts
export async function verifyWebhook(
  payload: string,
  signature: string,
  secret: string
): Promise<boolean> {
  const hmac = crypto.createHmac('sha256', secret);
  const expected = hmac.update(payload).digest('hex');
  return signature === expected;
}

export async function handleWebhook(event: WebhookEvent) {
  switch (event.type) {
    case 'card.created':
      // Handle card creation
      break;
    case 'card.updated':
      // Handle card update
      break;
    case 'card.deleted':
      // Handle card deletion
      break;
  }
}
```

## Best Practices

<AccordionGroup>
  <Accordion title="Use Minimal Scopes">
    Only request the minimum OAuth scopes needed for your tools to function. Users are more likely to approve limited permissions.
  </Accordion>

  <Accordion title="Cache Responses">
    Cache API responses when appropriate to reduce API calls and improve performance:

    ```typescript
    const cache = new Map<string, { data: any; expires: number }>();

    execute: async ({ credentials, parameters }) => {
      const cacheKey = JSON.stringify(parameters);
      const cached = cache.get(cacheKey);

      if (cached && cached.expires > Date.now()) {
        return cached.data;
      }

      const data = await fetchFromAPI(credentials, parameters);
      cache.set(cacheKey, { data, expires: Date.now() + 60000 }); // 1 min

      return data;
    }
    ```
  </Accordion>

  <Accordion title="Handle Rate Limits">
    Implement exponential backoff for rate-limited endpoints:

    ```typescript
    async function fetchWithRetry(url: string, options: RequestInit, retries = 3) {
      for (let i = 0; i < retries; i++) {
        const response = await fetch(url, options);

        if (response.status === 429) {
          const retryAfter = parseInt(response.headers.get('Retry-After') || '1');
          await new Promise(resolve => setTimeout(resolve, retryAfter * 1000));
          continue;
        }

        return response;
      }

      throw new Error('Max retries exceeded');
    }
    ```
  </Accordion>

  <Accordion title="Validate Input">
    Always validate tool parameters before making API calls:

    ```typescript
    inputSchema: {
      type: 'object',
      properties: {
        cardId: {
          type: 'string',
          pattern: '^[a-f0-9]{24}$', // Trello card ID format
          description: 'Trello card ID',
        },
      },
      required: ['cardId'],
    }
    ```
  </Accordion>
</AccordionGroup>

## Testing Checklist

Before submitting a custom integration:

- [ ] OAuth flow works end-to-end
- [ ] All tools execute successfully
- [ ] Error messages are user-friendly
- [ ] Rate limiting is handled
- [ ] Token refresh works (if applicable)
- [ ] Input validation prevents invalid requests
- [ ] README includes setup instructions
- [ ] Test script passes
