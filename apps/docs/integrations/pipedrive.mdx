## Overview

Connect to Pipedrive via OAuth 2.0.

**Category:** CRM
**Auth Type:** OAuth 2.0

## Setup

<Steps>
  <Step title="Create OAuth App">
    Create an OAuth application in Pipedrive developer portal.
  </Step>

  <Step title="Configure Callback">
    Set redirect URL: `https://api.authlane.com/api/v1/oauth/callback`
  </Step>

  <Step title="Add to Authlane">
    ```bash
    curl -X POST https://api.authlane.com/api/v1/admin/services/pipedrive/credentials \
      -H "Authorization: Bearer YOUR_ADMIN_API_KEY" \
      -H "Content-Type: application/json" \
      -d '{
        "tenantId": "your-tenant-id",
        "clientId": "YOUR_CLIENT_ID",
        "clientSecret": "YOUR_CLIENT_SECRET"
      }'
    ```
  </Step>
</Steps>
