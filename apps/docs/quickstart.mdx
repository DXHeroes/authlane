title: 'Quickstart'
description: 'Connect an end user without exposing your API key'
---

## 1. Create a server-side client

```bash
pnpm add @authlane/sdk
```

```typescript
import { Authlane } from '@authlane/sdk';

export const authlane = new Authlane({
  apiKey: process.env.AUTHLANE_API_KEY!,
  baseUrl: process.env.AUTHLANE_URL!,
});
```

<Warning>The scoped API key belongs only on your server. The SDK rejects browser usage.</Warning>

## 2. Create a connect session

In an authenticated route in your SaaS backend:

```typescript
const { data, error } = await authlane.connectSessions.create({
  externalUserId: currentUser.id,
  allowedServices: ['github', 'slack'],
  allowedOrigin: 'https://app.example.com',
  expiresInSeconds: 600,
});

if (error) return Response.json({ error }, { status: 400 });
return Response.json({ connectUrl: data.url });
```

Authlane stores only a hash of the short-lived session token. The session is restricted to one tenant, external user, service allowlist, parent origin, and expiry.

## 3. Render the hosted connection UI

```bash
pnpm add @authlane/react
```

```tsx
import { AuthlaneConnect } from '@authlane/react';

export function Integrations({ connectUrl }: { connectUrl: string }) {
  return (
    <AuthlaneConnect
      connectUrl={connectUrl}
      onEvent={(event) => console.log(event)}
    />
  );
}
```

OAuth authorization and callbacks stay on the Authlane origin. No SaaS API key reaches the iframe.

## 4. Read capabilities

```typescript
const { data: capabilities, error } = await authlane.capabilities.get({
  externalUserId: currentUser.id,
  format: 'mcp',
});
```

The response contains every enabled service, its effective `connected`, `disconnected`, `expired`, or `error` status, and tool definitions only for usable connections.

## 5. Call the provider directly

```bash
pnpm add @authlane/integration-github
```

```typescript
import github from '@authlane/integration-github';

const { data: credential } = await authlane.credentialLeases.create({
  externalUserId: currentUser.id,
  serviceId: 'github',
});

if (!credential) throw new Error('GitHub is not connected');

const { data: repositories, error } = await github.execute(
  'github_list_repos',
  { limit: 20 },
  credential
);
```

The GitHub request originates from your backend. Authlane is not in the provider data path. Never return the credential lease to browser code or persist it.
