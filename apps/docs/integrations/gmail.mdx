---
title: Gmail
description: Use the local Gmail adapter with Authlane credentials
---

Install the published adapter in the SaaS or agent runtime that will call Gmail:

```bash
pnpm add @authlane/integration-gmail
```

```typescript
import adapter from @authlane/integration-;

const definitions = adapter.definitions;
const result = await adapter.execute(toolName, input, credential);
```

Get `credential` from the server-side Authlane credentials endpoint. The adapter calls Gmail directly; tool inputs and provider responses do not pass through Authlane.
