---
title: Slack
description: Use the local Slack adapter with Authlane credentials
---

Install the published adapter in the SaaS or agent runtime that will call Slack:

```bash
pnpm add @authlane/integration-slack
```

```typescript
import adapter from @authlane/integration-;

const definitions = adapter.definitions;
const result = await adapter.execute(toolName, input, credential);
```

Get `credential` from the server-side Authlane credentials endpoint. The adapter calls Slack directly; tool inputs and provider responses do not pass through Authlane.
