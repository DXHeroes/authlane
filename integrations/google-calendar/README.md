# @authlane/integration-google-calendar

Google Calendar tool definitions and a local direct-execution adapter for Authlane.

```bash
pnpm add @authlane/integration-google-calendar
```

Use the canonical tools through `@authlane/ai`, or import this package when building a custom local
runtime. Authlane manages connection state and fresh access-only credential leases; provider calls
execute directly from your trusted runtime to Google Calendar.
