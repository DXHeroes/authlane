title: 'Self-Hosting Guide'
description: 'Run the complete Authlane control plane as one application service'
---

Authlane runs one application container plus PostgreSQL 16 and Redis 7. The application container includes the dashboard, connect UI, API, OAuth callbacks, migrations, and token-refresh worker.

## Docker Compose

```bash
cp .env.example .env
openssl rand -hex 32
openssl rand -base64 32
```

Set the values as `ENCRYPTION_KEY` and `BETTER_AUTH_SECRET`. Set `APP_URL` to the public HTTPS origin.

```bash
docker compose up --build -d
curl --fail http://localhost:3000/health
```

Only the Authlane port is exposed. PostgreSQL and Redis stay on the internal network. The application applies migrations on startup.

## Optional monitoring

```bash
docker compose --profile monitoring up -d
```

Prometheus reads `/metrics`; restrict that route at your ingress in production.

## Managed PostgreSQL and Redis

Deploy `apps/api/Dockerfile` as one service and configure:

```dotenv
NODE_ENV=production
APP_URL=https://authlane.example.com
BETTER_AUTH_URL=https://authlane.example.com
BETTER_AUTH_SECRET=...
DATABASE_URL=postgresql://...
REDIS_URL=rediss://...
ENCRYPTION_KEY=...
API_PORT=3000
```

The final image uses Node.js 22, pnpm 10, and a non-root runtime user.

## Performance check

On a warm instance with 2 vCPU / 1 GB:

```bash
PERF_BASE_URL=https://authlane.example.com \
PERF_API_KEY=ak_... \
PERF_EXTERNAL_USER_ID=user_123 \
pnpm test:performance
```

The default acceptance threshold is 500 requests per second with capability-read P95 below 100 ms.
