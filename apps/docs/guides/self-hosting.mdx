## Overview

Authlane is designed to be self-hosted. This guide covers deployment options from local development to production.

## Architecture

Authlane requires:

- **PostgreSQL** (14+) - Primary database
- **Redis** (6+) - Job queue for token refresh
- **Node.js** (22+) - API server runtime

```
┌─────────────────┐
│   Your App      │
└────────┬────────┘
         │
         ▼
┌─────────────────┐     ┌─────────────────┐
│  Authlane API   │────▶│   PostgreSQL    │
│   (Node.js)     │     │   (Database)    │
└────────┬────────┘     └─────────────────┘
         │
         ▼
┌─────────────────┐
│     Redis       │
│  (Job Queue)    │
└─────────────────┘
```

## Quick Start (Docker Compose)

The fastest way to get started:

<Steps>
  <Step title="Clone Repository">
    ```bash
    git clone https://github.com/authlane/authlane.git
    cd authlane
    ```
  </Step>

  <Step title="Configure Environment">
    ```bash
    cp .env.example .env
    ```

    Edit `.env`:
    ```bash
    # Database
    DATABASE_URL=postgresql://authlane:authlane@postgres:5432/authlane

    # Encryption (IMPORTANT: Generate secure key)
    ENCRYPTION_KEY=$(openssl rand -hex 32)

    # API
    API_PORT=3000
    API_HOST=0.0.0.0
    CORS_ORIGIN=https://yourapp.com

    # Redis
    REDIS_URL=redis://redis:6379

    # Environment
    NODE_ENV=production
    ```
  </Step>

  <Step title="Start Services">
    ```bash
    docker compose -f docker/docker-compose.yml up -d
    ```

    This starts:
    - PostgreSQL (port 5432)
    - Redis (port 6379)
    - Authlane API (port 3000)
  </Step>

  <Step title="Run Migrations">
    ```bash
    docker compose -f docker/docker-compose.yml exec api pnpm db:migrate
    ```
  </Step>

  <Step title="Seed Database">
    ```bash
    docker compose -f docker/docker-compose.yml exec api pnpm db:seed
    ```
  </Step>

  <Step title="Verify">
    ```bash
    curl http://localhost:3000/api/v1/health
    # Response: {"status":"ok","timestamp":"2025-11-27T..."}
    ```
  </Step>
</Steps>

**That's it!** Authlane is now running at `http://localhost:3000`.

## Manual Installation

For more control over the deployment:

### Prerequisites

<CodeGroup>

```bash Ubuntu/Debian
# Install PostgreSQL
sudo apt-get update
sudo apt-get install postgresql-14

# Install Redis
sudo apt-get install redis-server

# Install Node.js 22
curl -fsSL https://deb.nodesource.com/setup_22.x | sudo -E bash -
sudo apt-get install -y nodejs

# Install pnpm
npm install -g pnpm
```

```bash macOS
# Install PostgreSQL
brew install postgresql@14
brew services start postgresql@14

# Install Redis
brew install redis
brew services start redis

# Install Node.js 22
brew install node@22

# Install pnpm
npm install -g pnpm
```

</CodeGroup>

### Installation Steps

<Steps>
  <Step title="Create Database">
    ```bash
    psql postgres
    ```

    ```sql
    CREATE DATABASE authlane;
    CREATE USER authlane WITH PASSWORD 'your_secure_password';
    GRANT ALL PRIVILEGES ON DATABASE authlane TO authlane;
    ```
  </Step>

  <Step title="Clone and Install">
    ```bash
    git clone https://github.com/authlane/authlane.git
    cd authlane
    pnpm install
    ```
  </Step>

  <Step title="Configure Environment">
    ```bash
    cp .env.example .env
    ```

    Edit `.env` with your database credentials
  </Step>

  <Step title="Build">
    ```bash
    pnpm build
    ```
  </Step>

  <Step title="Run Migrations">
    ```bash
    cd packages/database
    pnpm drizzle-kit migrate
    ```
  </Step>

  <Step title="Start API">
    ```bash
    cd apps/api
    pnpm start
    ```
  </Step>
</Steps>

## Production Deployment

### Environment Variables

<ParamField path="DATABASE_URL" type="string" required>
  PostgreSQL connection string

  Example: `postgresql://user:pass@host:5432/dbname`
</ParamField>

<ParamField path="ENCRYPTION_KEY" type="string" required>
  32-byte hex key for credential encryption

  **Generate with:** `openssl rand -hex 32`

  <Warning>Never reuse keys across environments or rotate without migrating data</Warning>
</ParamField>

<ParamField path="REDIS_URL" type="string" required>
  Redis connection string for BullMQ

  Example: `redis://localhost:6379`
</ParamField>

<ParamField path="API_PORT" type="number" default="3000">
  Port for API server
</ParamField>

<ParamField path="API_HOST" type="string" default="0.0.0.0">
  Host binding for API server
</ParamField>

<ParamField path="CORS_ORIGIN" type="string" required>
  Allowed CORS origins (comma-separated)

  Example: `https://app.com,https://widget.app.com`
</ParamField>

<ParamField path="NODE_ENV" type="string" default="development">
  Environment: `development` | `production`
</ParamField>

<ParamField path="LOG_LEVEL" type="string" default="info">
  Logging level: `debug` | `info` | `warn` | `error`
</ParamField>

### Docker Production Setup

#### Multi-Stage Dockerfile

```dockerfile
# Build stage
FROM node:22-alpine AS builder

WORKDIR /app

COPY package.json pnpm-lock.yaml ./
RUN npm install -g pnpm && pnpm install --frozen-lockfile

COPY . .
RUN pnpm build

# Production stage
FROM node:22-alpine

WORKDIR /app

RUN npm install -g pnpm

COPY --from=builder /app/package.json /app/pnpm-lock.yaml ./
COPY --from=builder /app/node_modules ./node_modules
COPY --from=builder /app/apps/api/dist ./apps/api/dist
COPY --from=builder /app/packages ./packages

ENV NODE_ENV=production
EXPOSE 3000

CMD ["node", "apps/api/dist/index.js"]
```

#### Build and Run

```bash
# Build image
docker build -t authlane:latest .

# Run with docker-compose
docker compose up -d
```

### Kubernetes

<CodeGroup>

```yaml deployment.yaml
apiVersion: apps/v1
kind: Deployment
metadata:
  name: authlane-api
spec:
  replicas: 3
  selector:
    matchLabels:
      app: authlane-api
  template:
    metadata:
      labels:
        app: authlane-api
    spec:
      containers:
      - name: api
        image: authlane:latest
        ports:
        - containerPort: 3000
        env:
        - name: DATABASE_URL
          valueFrom:
            secretKeyRef:
              name: authlane-secrets
              key: database-url
        - name: ENCRYPTION_KEY
          valueFrom:
            secretKeyRef:
              name: authlane-secrets
              key: encryption-key
        - name: REDIS_URL
          value: redis://authlane-redis:6379
        resources:
          requests:
            memory: "256Mi"
            cpu: "250m"
          limits:
            memory: "512Mi"
            cpu: "500m"
```

## Database Management

### Running Migrations

```bash
# Generate new migration
cd packages/database
pnpm drizzle-kit generate

# Apply migrations
pnpm drizzle-kit migrate
```

### Backups

#### Automated Backups (PostgreSQL)

```bash
#!/bin/bash
# backup.sh

DATE=$(date +%Y%m%d_%H%M%S)
BACKUP_DIR=/backups
DB_NAME=authlane

pg_dump $DATABASE_URL > $BACKUP_DIR/authlane_$DATE.sql

# Keep last 30 days
find $BACKUP_DIR -name "authlane_*.sql" -mtime +30 -delete
```

Schedule with cron:

```bash
# Run daily at 2 AM
0 2 * * * /path/to/backup.sh
```

#### Restore from Backup

```bash
psql $DATABASE_URL < backup.sql
```

### Scaling PostgreSQL

For high-traffic deployments:

- **Read replicas**: Use [pg_pool](https://www.pgpool.net/)
- **Connection pooling**: Use [PgBouncer](https://www.pgbouncer.org/)
- **Managed services**: AWS RDS, Google Cloud SQL, Supabase

### Metrics

Key metrics to monitor:

- **API latency**: p50, p95, p99
- **OAuth success rate**: % successful connections
- **Token refresh failures**: Failed refresh jobs
- **Database connections**: Active pool size
- **Redis queue depth**: Pending jobs

Example with Prometheus:

```yaml
# prometheus.yml
scrape_configs:
  - job_name: 'authlane'
    static_configs:
      - targets: ['localhost:3000']
    metrics_path: '/metrics'
```

## Security Hardening

<Warning>
  Follow these security practices for production deployments.
</Warning>

### HTTPS Only

```nginx
# nginx config
server {
    listen 80;
    server_name api.authlane.com;
    return 301 https://$server_name$request_uri;
}

server {
    listen 443 ssl http2;
    server_name api.authlane.com;

    ssl_certificate /path/to/cert.pem;
    ssl_certificate_key /path/to/key.pem;

    location / {
        proxy_pass http://localhost:3000;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
    }
}
```

### Rate Limiting

Configure in `.env`:

```bash
RATE_LIMIT_WINDOW_MS=900000  # 15 minutes
RATE_LIMIT_MAX=100            # 100 requests per window
```

### Firewall Rules

Only expose necessary ports:

```bash
# Allow HTTPS
sudo ufw allow 443/tcp

# Allow SSH (if needed)
sudo ufw allow 22/tcp

# Block PostgreSQL from external
sudo ufw deny 5432/tcp

# Block Redis from external
sudo ufw deny 6379/tcp
```

### Environment Isolation

Never use production credentials in development:

```bash
# .env.development
DATABASE_URL=postgresql://localhost:5432/authlane_dev
ENCRYPTION_KEY=dev_key_1234567890...

# .env.production (not in git!)
DATABASE_URL=postgresql://prod:pass@db.cloud.com:5432/authlane
ENCRYPTION_KEY=<secure-production-key>
```

## Troubleshooting

<AccordionGroup>
  <Accordion title="Database connection failed">
    **Error:** `ECONNREFUSED` or `connection refused`

    **Solutions:**
    - Check `DATABASE_URL` format
    - Verify PostgreSQL is running: `pg_isready`
    - Check firewall rules
    - Verify credentials
  </Accordion>

  <Accordion title="Redis connection failed">
    **Error:** `Redis connection timeout`

    **Solutions:**
    - Verify Redis is running: `redis-cli ping`
    - Check `REDIS_URL` format
    - Check network connectivity
  </Accordion>

  <Accordion title="Token refresh jobs not running">
    **Error:** Connections expiring without refresh

    **Solutions:**
    - Verify Redis is connected
    - Check BullMQ worker logs
    - Ensure `NODE_ENV=production`
  </Accordion>

  <Accordion title="High API latency">
    **Solutions:**
    - Check database query performance
    - Add read replicas
    - Enable connection pooling
    - Scale horizontally (more API instances)
  </Accordion>
</AccordionGroup>
