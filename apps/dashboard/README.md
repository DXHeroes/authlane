# Authlane Dashboard

Admin dashboard for managing Authlane integrations and services.

## Tech Stack

- React 18, TypeScript, Vite
- Tailwind CSS (shadcn/ui compatible)
- React Router, TanStack Query

## Features

- Authentication (login/register)
- Dashboard with stats overview
- Services configuration with OAuth settings
- Enable/disable integrations
- Custom OAuth app configuration

## Development

pnpm install
pnpm dev     # localhost:5173
pnpm build
pnpm type-check
